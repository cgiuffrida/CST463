PA3 RUN 20 — FINAL EXPERIMENT ADDENDUM

Purpose
Test whether increasing AdamW weight decay from 0.001 to 0.003 improves
generalization beyond run 19. This was a controlled, single-factor comparison.

Configuration
All other settings matched run 19: seed 0, 90 epochs, batch size 64, four
loader workers, 128 x 128 images, channels [32,64,256,512,1024], and the extra
256->256 convolution after the third pooling operation. Dropout remained 0.2.
AdamW started at learning rate 0.003, with cosine decay over 90 epochs toward
0.00003. Both runs used fresh weights and the same pinned ImageNet-100 dataset.
Parameter count remained 6,763,748.

Results

Best validation accuracy            77.00%          77.20%

Interpretation
Stronger weight decay improved the final-five validation average by 0.092
percentage points and final-epoch accuracy by 0.24 points, with lower validation
loss and essentially unchanged runtime. This was a small improvement, much
smaller than the earlier combined dropout/weight-decay change from run 18 to
run 19. It suggests diminishing returns from this particular adjustment; it
does not establish an accuracy ceiling for the architecture or dataset.

Both configurations were tested at seed 0 only for this 90-epoch comparison.
The small difference does not demonstrate reliable superiority across seeds.
The five final epochs are correlated observations, not independent replications.

Final selection
Select run 20 as the best observed completed configuration: it has the highest
final-five validation average, lower validation loss than run 19, and no
material computational penalty. Treat this as a narrow empirical selection,
not a statistically established advantage or a proven optimal configuration.
The instructor's private-evaluation accuracy remains unknown.
